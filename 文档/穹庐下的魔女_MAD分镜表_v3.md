## 贯穿全片的三个核心

1. **同曲异主**：鸿雁 托雷（征服者的辽阔）→ 女主（被俘）→ 托列哥那（另一个灭族之女）——一首歌三个主人，两个都没有家
2. **"北方家乡"错位**：蒙古人的北方家乡还在；女主和托列哥那的家乡都没了——鸿雁每唱一次"北方家乡"，就是一次刺
3. **同盟而非主仆**：托列哥那信任女主是真的（同类相认），女主的感情给了这个"唯一懂她失去一切的人"——帐中戏是同盟也是取暖

## 情绪弧线

```
托雷的辽阔 → 她被俘(破碎) → 她的家(闪回·暖) → 异乡(冷) → 帐中同盟(最重) → 静默 → 信天游爆发(恨) → 雁归(宿命)
```
