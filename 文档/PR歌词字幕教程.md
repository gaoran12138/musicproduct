# Premiere Pro 歌词字幕添加指南（《晴天》）

本目录已有：
- `晴天_歌词.srt` — 带时间轴的歌词字幕（43 句，繁体原版，可直接导入 PR）
- `晴天_歌词.lrc` — 同内容 LRC 格式（PotPlayer 等播放器卡拉OK用）
- `晴天子幕A_歌词.srt` — 纯歌词（底部字幕用）
- `晴天子幕B_和弦右手.srt` — 和弦+右手（顶部字幕用）
- `仅供参考.srt` — 全片显示的"仅供参考"水印字幕
- `晴天_歌词+和弦+右手.srt` — 三行合一版（和弦/右手/歌词，单轨方案）

## 怎么让两条字幕同时显示（重要修正）

**PR 的机制限制：一次只能有一条"活动"字幕轨**——字幕面板里的"切换字幕轨"是在轨之间切换，不是同时显示。两条字幕轨同时显示在 PR 里做不到。

**正确做法：全部合并进一条字幕轨。**

1. **歌词+和弦+右手**：直接导入 `晴天_歌词+和弦+右手.srt`
   —— 一条字幕轨，每条字幕三行（和弦 / 右手 / 歌词），天然"同时显示"
2. **"仅供参考"水印**：不要用字幕！用 `文字工具` 打上"仅供参考" → `窗口 → 基本图形` → 拖到右上角、缩小字号、调低透明度（20~30%）→ 作为图形层放视频轨上方，全程显示
3. **样式说明**：单条字幕内所有行共用一个样式（PR 无法给同一字幕的不同行设不同字号）；想区分就接受三行同字号，或把和弦行并入基本图形手动对时间（43 句，不推荐）

## 第一步：准备工程

1. 新建 PR 项目，把素材拖入：你的视频素材 + 音频轨（比如之前分离的 `晴天_分轨v2\karaoke\04_伴奏_含和声.wav`）
2. 音频和视频对好位置

## 第二步：导入歌词字幕

**方式 A（推荐）：导入 SRT**
1. 菜单 `文件 → 导入`，选择 `晴天_歌词.srt`
2. 它会自动生成一条**字幕轨道（Captions）**在时间轴最上方
3. 把字幕轨整体拖动，让第一句歌词（29.36 秒处）对准伴奏里人声出现的位置

**方式 B：手动粘贴**
1. `窗口 → 字幕`（Captions 面板）
2. 点"新建字幕轨道"，逐句粘贴歌词、填时间码
（有 SRT 就别用这个了，A 更快）

## 第三步：调整歌词样式

1. 时间轴上选中任意一条字幕块 → 打开 `窗口 → 基本图形`（Essential Graphics）→ `编辑`
2. 建议设置：
   - **字体**：思源黑体 / 微软雅黑（中文字体，别用默认拉丁字体）
   - **大小**：40~60
   - **位置**：屏幕下方 1/4 处（居中）
   - **描边**：打开"描边"，宽度 2~4，黑色 —— 白字黑边最清晰
   - **阴影**：适当加一点，增强可读性
3. 样式改好后，选中所有字幕块 → 右键 → 应用同样的样式（或直接在"字幕样式"里存一个样式）

## 第三步补充：字体/样式应用到全部字幕

只选中**一条**字幕改字体，只会变那一条。要全部生效：

1. **全选字幕轨**：在时间轴上点字幕轨最左边的**轨道头**（轨道名称区域）→ 该轨所有字幕块全选（全部高亮）
2. 打开 `窗口 → 基本图形 → 编辑`，改字体/大小/颜色/描边 → 全部一起变
3. 备选：同一次导入的 SRT 字幕共用一个**样式（Caption Style）**，在基本图形顶部找到样式下拉框，修改该样式的字体属性 → 所有用此样式的字幕一起更新
4. 防坑：不要用"复制粘贴属性"（Ctrl+Alt+V）传播字幕样式，容易把文字内容也粘过去；样式已乱时，删掉字幕轨重新导入 SRT 最省心

## 第四步：时间轴对齐（重要）

- SRT 是按原曲 269.7 秒做的。如果你的伴奏被变速/剪辑过，歌词会错位：
  - 小错位：选中所有字幕块一起前后拖动
  - 大错位：字幕面板里修改第一句时间码，或把整条字幕轨"右移/左移"对应秒数
- 第一句 `故事的小黃花` 应在 00:29.4 左右出现（原曲前奏 ~29 秒）

## 第五步：卡拉OK 效果（逐字高亮）

**PR 没有原生"逐字卡拉OK"功能**，常用替代方案：

| 方案 | 效果 | 难度 |
|---|---|---|
| 逐句显示（直接用 SRT） | 整句出现/消失 | ⭐ 最简单 |
| 整句渐显动画 | 每句淡入 | ⭐⭐ 基本图形加不透明度关键帧 |
| 逐字变色 | 真正的卡拉OK | ⭐⭐⭐⭐⭐ 需要剪映/AE |

**想要逐字卡拉OK 的实用路线**：
1. 用**剪映**（免费）导入伴奏 → 歌词 → "自动识别/卡拉OK"功能一键生成逐字歌词
2. 把剪映歌词字幕部分**导出为透明通道视频**（或绿幕视频）
3. 回到 PR 里叠在你的视频上（混合模式选"滤色"或抠绿幕）

## 第六步：导出（设置清单）

1. `文件 → 导出 → 媒体`（Ctrl+M）

2. **格式**：H.264 → 输出 MP4（B站/抖音/YouTube 通用）
   预设选 **"匹配源 - 自适应高比特率"**（Match Source - Adaptive High Bitrate）

3. **字幕（最关键！）**：导出对话框里找到 **"字幕"（Captions）** 区域，选 **"烧录"（Burn In）**
   - 烧录 = 歌词直接渲染进画面（硬字幕），任何平台都能看
   - 如果选了"嵌入/无"，视频里可能**看不到歌词** → 这是最常见的翻车点

4. **源范围**：确认是"整个序列"（Entire Sequence），别只导出一小段

5. **视频设置**：分辨率/帧率保持"匹配源"（比如 1080p 30fps），不要动
   - 发抖音/视频号（竖屏）→ 源是 1080×1920 就按源来
   - 发 B站/YouTube（横屏）→ 1920×1080

6. **比特率**（视频）：
   - 1080p：目标 10~16 Mbps（"自适应高比特率"预设一般已够）
   - 预览用可以降到 5 Mbps

7. **音频**：AAC，**320 kbps**（音乐向视频，音质重要）；PR 默认 192k，手动调到 320

8. **性能**：勾选 **"硬件加速"**（你的 RTX 4070 有 NVENC 硬编码，导出速度翻好几倍）；勾选"最高渲染质量"

9. 导出后**立刻检查**：视频里歌词是否显示、是否清晰、声音是否正常

### 导出参考（常见平台）
| 平台 | 分辨率 | 帧率 | 码率建议 |
|---|---|---|---|
| B站 | 1920×1080 | 30 | 12 Mbps |
| YouTube | 1920×1080 | 30 | 16 Mbps |
| 抖音/视频号 | 1080×1920 | 30 | 12 Mbps |

## 常见问题

- **导入 SRT 后字幕不显示**：确认字幕轨在视频轨之上，且导出时选了烧录字幕
- **歌词变"口口口"（乱码）**：SRT 是 UTF-8 编码，PR 一般没问题；若乱码，用记事本打开 SRT 另存为"UTF-8 with BOM"再导入
- **字体显示不出中文**：样式里手动选一个中文字体（如"微软雅黑"）
- **对不上拍**：先听人声出现时间，再整体平移字幕轨
